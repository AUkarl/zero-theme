{{- /* ============================================================ cms/str.html — 把后台 data 里的一个值收成字符串 ------------------------------------------------------------ 用法：{{- $url := partial "cms/str.html" (dict "value" $raw) -}} 为什么要包一层：Hugo 的 string 遇到数组 / 对象会直接报错（unable to cast ... to string）， 而 data 目录里的 json 是后台写出来的，字段类型不该由模板赌它一定对。 容器一律收成空串 —— 坏数据最多让这一项不显示，不该让整个站点构建失败。 顺带 trim 掉首尾空白：后台多打一个空格是常事，判空时才不会被蒙过去。 ============================================================ */ -}} {{- $v := .value -}} {{- $out := "" -}} {{- if not (or (reflect.IsMap $v) (reflect.IsSlice $v)) -}} {{- $out = trim (string ($v | default "")) " " -}} {{- end -}} {{- return $out -}}
