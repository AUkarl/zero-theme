{{- /* ============================================================ partials/shortcodes/safe-url.html — 短代码外部地址的 http/https 白名单 ------------------------------------------------------------ 用法：{{- $src := partial "shortcodes/safe-url.html" (.Get "src") -}} · 空值 → 返回 ""（调用方据此提示「缺参数」） · http:// https:// → 原样返回 · //host/path → 原样返回（协议相对，浏览器补当前协议） · 站内路径 / 相对路径（没有协议头）→ 原样返回 · 其它协议（javascript: / data: / vbscript: / file: / …）→ 返回 "" 为什么要这一层：短代码是给后台编辑器插进正文用的，地址来自可编辑的字段； ``、``、`` 直接吃 javascript: 就是自伤型 XSS。 ------------------------------------------------------------ `return` 只认模板体顶层：写进 if/range 分支里，Hugo 会把它当成一个叫 return 的函数去数参数（0.165 报 "wrong number of args for return: want 0 got 1"）， 一个短代码就能把整站构建打死。所以这里把结果一路算进 $safe，最后只在顶层 return。 ============================================================ */ -}} {{- $u := trim (string (. | default "")) " " -}} {{- $lower := lower $u -}} {{- $safe := $u -}} {{- if not (or (hasPrefix $lower "http://") (hasPrefix $lower "https://") (hasPrefix $u "//")) -}} {{- /* 出现「<字母…>:」这种协议头就不是站内路径，也不在上面放行的协议里，一律拒绝 */ -}} {{- if findRE `^[a-zA-Z][a-zA-Z0-9+.-]*:` $u -}} {{- $safe = "" -}} {{- end -}} {{- end -}} {{- return $safe -}}
