{{- /* ============================================================ zero/md-text.html — 后台「前端管理」里那些纯文本字段的渲染器 ------------------------------------------------------------ 用法： {{- partial "zero/md-text.html" (dict "text" $p) -}} 支持两样东西，够这些「一两句话」的字段用了： · 普通 Markdown 内联写法：`[文字](https://…)`、`[文字](/about/)`、`**加粗**`； · 站内短链 `[[文章标识符]]` —— 与评论/时刻里那套一致，渲染成 <短链前缀><标识符>/。 不解析标题、列表、图片这类块级 Markdown：这些字段本来就各占一个

/

  • ， 真需要整篇排版应该去写文章，而不是塞进关于页的一段话里。 先把 [[标识符]] 换成普通 Markdown 链接，再统一 markdownify —— 内链 / 外链 / 短链只走一条渲染路，输出口径不会分叉。 注意：return 只能写在模板顶层（放进 if 里会报 wrong number of args）， 所以这里是「先算进变量、末尾统一 return」的写法。 ============================================================ */ -}} {{- $text := .text | default "" -}} {{- $base := partial "zero/short-base.html" . -}} {{- $out := "" -}} {{- if ne (trim $text " \t\r\n") "" -}} {{- $linked := replaceRE `\[\[([^\[\]\s]+)\]\]` (printf "[%s](%s%s/)" "$1" $base "$1") $text -}} {{- $out = $linked | markdownify -}} {{- end -}} {{- return $out -}}
